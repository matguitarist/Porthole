The first version of Porthole: your Docker server's containers and logs in a native Mac app, over SSH, with nothing to install on the server.

- See every container with its icon, health, CPU and memory, and start, stop or restart it
- Read live logs with levels detected for most formats, filters, search, and Docker insights for crashes, health checks and restart loops
- An overview of the server: load, disks, what needs a look, the last day's events, and every container's warnings and errors
- Get alerts on this Mac, or on your phone through Gotify, when a container crashes, turns unhealthy, keeps restarting, or logs new errors
- Ignore known noise, read a compose stack as one log, and clear logs on the server
- A menu bar icon with the server's state, open at login, and automatic updates
