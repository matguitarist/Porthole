- Porthole tells you when Docker itself is busy: the overview's CPU tile shows "Docker at 507%" and you get an alert when dockerd has used more than one and a half cores for five minutes.
- A Docker restart no longer looks like trouble: warnings and errors from the minutes around it don't count, and the overview says how many it left out.
- A container stopped by `docker stop`, a restart, or Docker shutting down no longer alerts as a crash, whatever its exit code.
- A new install asks for your server's SSH address, with a Set Up Your Server page.
- The agent's web page shows the same Docker busy warning and restart note, and its overview icons are the right size.
